# Resume Job Matcher

A machine learning project designed to match candidate resumes with job descriptions using natural language processing (NLP) and similarity matching.

## Features
- Cleans and preprocesses resume text data
- Extracts key technical skills and qualifications
- Matches resumes to job descriptions based on semantic similarity
- Saves and loads trained pipeline models using `joblib`

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, NLTK
- **Model Storage:** Joblib

## Dataset
The model uses `UpdatedResumeDataSet.csv`, containing labeled resume text across diverse domains.
